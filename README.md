# RP Prompt Hub

Однофайловый статичный сайт-витрина РП-промптов для комьюнити:
**копия в буфер в один клик** + **история версий** каждого промпта (из git).

- Только РП-промпты (кураторский список в `manifest.json`), ничего лишнего.
- Работает офлайн: открыл `index.html` — всё уже внутри, сервер не нужен.
- Кнопки «Обратная связь» открывают Telegram с предзаполненным сообщением.

## Быстрый старт

```
start.cmd        # собрать сайт и открыть в браузере
```

или руками: `python build_rp_hub.py` → открыть `index.html`.

## Как устроено

| Файл | Назначение |
|------|-----------|
| `manifest.json` | Кураторский список промптов: файл, название, описание, модели, теги, флаг JB/крафт |
| `template.html` | UI сайта (тёмная тема, поиск, фильтры, модалка истории, дифф) |
| `build_rp_hub.py` | Сборка: читает манифест + файлы + git-историю → `index.html` |
| `index.html` | Готовый однофайловый сайт (можно хостить где угодно) |
| `serve.cmd` | Раздать сайт друзьям по локалке (порт 8765) |

## Настройка

1. **Telegram для обратной связи** — в `build_rp_hub.py`, блок `CONFIG`:
   `"tg_username": "YOUR_TG_USERNAME"` → впиши свой юзернейм без `@`.
   Кнопки будут открывать `t.me/<username>?text=...` с префиллом.
2. **Состав и описания** — правится в `manifest.json` (добавил файл →
   пересобери → история версий появится автоматически, если файл закоммичен).
   Если файл — копия другого промпта (например, русская версия стандарта),
   поставь `"noFollow": true`, чтобы история не уходила по rename-следу
   в историю исходного промпта и показывала только собственные версии.
3. **Заголовок/подзаголовок** — там же, в `CONFIG`.

## Как расшарить комьюнити

- **Онлайн (готово):** https://youlianvr.github.io/rp-prompt-hub/ — GitHub Pages,
  репозиторий `youlianvr/rp-prompt-hub` (ветка `main`, деплой из корня).
  Обновление: пересобрать `index.html` → запушить в тот репо.
- **Локально/по локалке:** `serve.cmd` → друзья из той же Wi-Fi сети открывают
  `http://ТВОЙ_ЛОКАЛЬНЫЙ_IP:8765`.
- **Другой статик-хостинг:** закинь `index.html` на Netlify / Cloudflare
  Pages (drag&drop одного файла). История версий вшита при сборке.

## Сброс истории версий

Версии в хабе берутся из git, но их показ можно «обнулить» без переписывания
истории: в `build_rp_hub.py` задан `RESET_AT` (ISO-дата). Коммиты старше этой
точки не попадают в сайт — история копится заново с момента сброса. Нужен
новый сброс: сдвинь `RESET_AT` на текущий момент и пересобери. `None` —
показывать всю историю.

## Примечание

Версии берутся из git-истории репозитория (`git log --follow`). Файл, который
ещё не коммитился, получит пометку «без истории». После коммита — пересобери.
